# Multiplications magiques 🪄 — CE2

Jeu pédagogique de **multiplications posées en colonnes**, conçu pour un écran de téléphone et utilisable sans installation.

## Jouer

[Ouvrir le jeu (GitHub Pages)](https://sims07.github.io/game-child-multiplication-colonne/)

> Pour la première publication, aller dans **Settings → Pages → Build and deployment → Source : GitHub Actions**. Ensuite, chaque modification de la branche `main` déclenche un déploiement automatique.

## Fonctionnement

- Multiplier par le chiffre des unités, en apprenant les retenues.
- Placer le zéro de décalage de la deuxième ligne.
- Multiplier par le chiffre des dizaines.
- Additionner les deux lignes en colonnes.
- Trois niveaux, douze exercices, indices et étoiles conservées dans le navigateur.

## Développement

Application autonome : tout est dans [`index.html`](./index.html), sans framework ni dépendance externe. Ouvrir directement le fichier dans un navigateur pour tester localement.
